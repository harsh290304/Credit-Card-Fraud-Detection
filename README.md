# Credit Card Fraud Detection

## Overview
This project uses Machine Learning techniques to detect fraudulent credit card transactions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## ML Techniques
- Logistic Regression
- StandardScaler
- Train-Test Split

## Results
- Training Accuracy: 95%
- Testing Accuracy: 92%

## Dataset
Credit Card Fraud Detection Dataset
